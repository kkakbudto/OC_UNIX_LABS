----------------------------------------------------------
Скрипт сборки исходных файлов (lab1.sh)

POSIX-совместимый shell-скрипт для безопасной компиляции исходного кода (C, C++) и сборки TeX-документов.

----------------------------------------------------------
Описание работы

Скрипт принимает на вход один файл, определяет его тип по расширению и выполняет сборку в временном каталоге. При успешной компиляции итоговый файл копируется в директорию, где находился исходный файл.

Скрипт обеспечивает безопасную очистку ресурсов: временная директория удаляется при любых сценариях завершения работы.

----------------------------------------------------------
Требования

Для корректной работы скрипта в системе должны быть установлены следующие инструменты:

- POSIX-совместимый интерпретатор оболочки (/bin/sh)

- Компилятор C (cc)

- Компилятор C++ (c++)

- Дистрибутив LaTeX (pdflatex)

----------------------------------------------------------
Настройка имени выходного файла

По умолчанию скомпилированный файл получит имя default_out (или default_out.pdf для TeX). Чтобы задать собственное имя, добавьте в исходный код комментарий, содержащий ключевое слово Output: и желаемое имя файла без пробелов.

----------------------------------------------------------
Поддерживаемые форматы

.c - компилируется с помощью cc -Wall -Wextra -O2

.cpp, .cc, .cxx - компилируются с помощью c++ -Wall -Wextra -O2

.tex - собирается с помощью pdflatex -interaction=nonstopmode

----------------------------------------------------------
Коды возврата ошибок

Скрипт использует информативные коды возврата для диагностики проблем:

0 — Сборка и копирование успешно завершены.

1 — Ошибка перехода во временную директорию.

2 — Ошибка аргументов: скрипт запущен без указания исходного файла.

3 — Ошибка файловой системы: указанный исходный файл не существует.

4 — Ошибка файловой системы: не удалось создать временную директорию (сбой mktemp).

5 — Ошибка формата: расширение файла не поддерживается.

6 — Ошибка возврата: скрипт не смог вернуться в исходный рабочий каталог.
