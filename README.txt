----------------------------------------------------------
Программа дедупликации файлов через жёсткие ссылки (hardlink_dedup)

Консольное приложение на C++17 для поиска файлов с одинаковым содержимым (по хэшу SHA-1) в указанном каталоге и замены дубликатов на жёсткие ссылки без вызова внешних программ.

----------------------------------------------------------
Описание работы

Программа рекурсивно обходит указанный пользователем каталог, формирует отсортированный список всех обычных файлов (символьные ссылки пропускаются) и вычисляет для каждого файла хэш SHA-1.

Для групп файлов с совпадающим хэшем дополнительно выполняется побайтовая проверка содержимого. Из каждой такой группы оставляется один экземпляр файла (приоритет у файла с наибольшим числом жёстких ссылок, далее по алфавиту пути), а остальные заменяются на жёсткие ссылки, указывающие на сохранённый экземпляр.

Если файл уже является жёсткой ссылкой на оставляемый экземпляр, повторная замена не выполняется. При замене сначала создаётся временная жёсткая ссылка в том же каталоге, после чего она переименовывается поверх дубликата — при возникновении ошибки исходные файлы не теряются.

----------------------------------------------------------
Требования

Для сборки и запуска программы в системе должны быть установлены следующие компоненты:

- Компилятор C++ с поддержкой стандарта C++17 (g++ в MSYS2 UCRT64 или UNIX/Linux)

- Библиотека OpenSSL (libcrypto, заголовочный файл openssl/evp.h)

- Утилита make (необязательно, при сборке через Makefile)

----------------------------------------------------------
Сборка

MSYS2 UCRT64 (Windows):

g++ -std=c++17 -O2 -Wall -Wextra -pedantic -o hardlink_dedup.exe main.cpp -lcrypto

UNIX / Linux:

make

(или g++ -std=c++17 -O2 -Wall -Wextra -pedantic -o hardlink_dedup main.cpp -lcrypto)

----------------------------------------------------------
Запуск и параметры командной строки

Формат запуска: ./hardlink_dedup.exe <каталог> [опции]

Поддерживаемые опции:

-n, --dry-run — предварительный просмотр планируемых действий без изменения файлов.

-q, --quiet — не выводить общий список файлов и их хэшей перед этапом дедупликации.

-h, --help — вывести справку по использованию программы и завершить работу.

----------------------------------------------------------
Коды возврата ошибок

Программа использует следующие коды возврата:

0 — Работа успешно завершена (либо выведена справка по ключу -h / --help).

1 — Ошибка аргументов командной строки, указанный путь не является существующим каталогом, ошибка открытия каталога либо ошибки при хэшировании файлов или создании жёстких ссылок.
