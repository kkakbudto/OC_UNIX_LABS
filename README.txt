----------------------------------------------------------
Программа дедупликации файлов через жёсткие ссылки (hardlink_dedup)

Консольное приложение на C++17 для поиска файлов с одинаковым содержимым (по хэшу SHA-1) в указанном каталоге и замены дубликатов на жёсткие ссылки без вызова внешних программ.

----------------------------------------------------------
Описание работы

Программа рекурсивно обходит указанный пользователем каталог (символьные ссылки пропускаются), удаляет оставшиеся от прерванных запусков временные файлы с префиксами .hardlink_dedup_tmp_ и .hardlink_tmp_, формирует отсортированный список всех обычных файлов и вычисляет для каждого файла хэш SHA-1 с помощью встроенной реализации стандарта FIPS 180-4.

Для групп файлов с совпадающим хэшем программа проверяет эквивалентность inode. Если файл уже является жёсткой ссылкой на оставляемый экземпляр, повторная замена не выполняется. Для остальных кандидатов дополнительно выполняется побайтовая проверка содержимого.

Из каждой группы дубликатов сохраняется один экземпляр (приоритет у файла с наибольшим числом жёстких ссылок, далее по алфавиту пути), а остальные заменяются на жёсткие ссылки, указывающие на сохранённый экземпляр.

При замене сначала создаётся временная жёсткая ссылка в том же каталоге с учётом PID процесса, после чего она переименовывается поверх дубликата. При возникновении ошибки переименования временная ссылка удаляется, а исходные файлы не теряются.

----------------------------------------------------------
Требования

Для сборки и запуска программы не требуются сторонние библиотеки. В системе должны быть установлены:

- Компилятор C++ с поддержкой стандарта C++17 (например, g++ в UNIX/Linux или MSYS2 UCRT64)

- Стандартная библиотека C++17 и заголовочный файл unistd.h

- Утилита make (при сборке через Makefile)

----------------------------------------------------------
Сборка

UNIX / Linux (через Makefile):

make

Команда соберёт исполняемый файл hardlink_dedup с флагами -std=c++17 -O2 -Wall -Wextra -pedantic. Для очистки результата сборки используется make clean.

MSYS2 UCRT64 (Windows):

g++ -std=c++17 -O2 -Wall -Wextra -pedantic -o hardlink_dedup.exe main.cpp

----------------------------------------------------------
Запуск и параметры командной строки

Формат запуска: ./hardlink_dedup [опции] [--] <каталог>

(в Windows / MSYS2: ./hardlink_dedup.exe [опции] [--] <каталог>)

Поддерживаемые опции:

-n, --dry-run — предварительный просмотр планируемых действий (включая очистку временных файлов и оценку освобождаемого места) без изменения файлов.

-q, --quiet — не выводить общий список файлов и их хэшей перед этапом дедупликации.

-h, --help — вывести справку по использованию программы и завершить работу.

-- — конец списка опций (позволяет указывать имена каталогов, начинающиеся с символа '-').

----------------------------------------------------------
Коды возврата ошибок

Программа использует следующие коды возврата:

0 — Работа успешно завершена (либо выведена справка по ключу -h / --help).

1 — Ошибка аргументов командной строки, указанный путь не является существующим каталогом, ошибка открытия каталога либо ошибки при хэшировании файлов, очистке временных файлов или создании жёстких ссылок.
