Лабораторные работы по курсу Операционные системы UNIX

Этот репозиторий содержит выполненные практические задания, направленные на изучение принципов работы ОС семейства UNIX и получение навыков взаимодействия с системой.

-----------------------------------------------------------
Структура репозитория:

Каждая лабораторная работа изолирована и располагается в собственной отдельной ветке. Для просмотра исходных кодов, скриптов и документации по конкретному заданию необходимо переключиться на соответствующую ветку. В главной ветке находится только общая информация о курсе.

-----------------------------------------------------------
Требования для запуска:

Для проверки и запуска разработанных скриптов потребуется любая UNIX-подобная операционная система (Linux, macOS, FreeBSD) или среда WSL. Перед запуском исполняемых файлов убедитесь, что им выданы соответствующие права.
